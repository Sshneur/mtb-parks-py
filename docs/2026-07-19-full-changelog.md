## 1. ЗАГРУЗКА ФОТО — БАГ Safari iOS 18.5.2

**Проблема:** Safari на iPhone не отправлял `multipart/form-data` (FormData). Сервер получал пустой `UploadFile`.

**Решение:** Переход на JSON через FileReader.
- `static/js/park.js`: вместо `FormData` — `FileReader.readAsDataURL()`, отправка `{"photo": "data:image/jpeg;base64,..."}`
- `api/park_routes.py`: приём JSON вместо `UploadFile`, декодинг base64, сохранение файла
- `api/admin_routes.py`: аналогично для админской загрузки

- **Офлайн-фолбэк**: если документ недоступен — показать кешированный `/`
- **activate**: удаление старых кешей (v1–v7)
- **Версия**: `CACHE_NAME = 'v8'`

## 7. OG-ТЕГИ И КАРТИНКА ДЛЯ СОЦСЕТЕЙ

**Проблема:** Старая OG-картинка была на 99.2% чёрной с микроскопическими элементами диаграммы — Telegram и соцсети не показывали превью.

**Решение:**
- Сгенерирована новая картинка 1200×630 через Pillow:
  - Тёмный градиентный фон
  - Крупный текст «ЧТО С ГРУНТОМ?» (Impact, 88pt)
  - Подзаголовок «Погода на трассах • Прогноз грунта»
  - Силуэты гор внизу
  - URL `gripchek.ru`
- Формат: JPEG (50kb) — некоторые краулеры лучше его понимают
- Формат: PNG (21kb) — оставлен для совместимости

**Файлы:** `static/og-image.jpg`, `static/og-image.png`, `gen_og.py`, `gen_og_jpg.py`
