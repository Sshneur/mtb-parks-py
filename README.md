# MTB Parks — Что с Грунтом?

Сервис мониторинга состояния грунта на MTB-трассах. Прогнозирует влажность почвы по погодным данным, показывает лучшее время для катания.

**Домен:** gripchek.ru

---

## Архитектура

### Бэкенд
- **FastAPI** (Python 3.12) — ASGI-сервер
- **SQLite** (WAL mode) — БД с почасовыми данными погоды
- **Open-Meteo API** — погодные данные (история + прогноз)

### Фронтенд
- **Vanilla JS** — без фреймворков
- **CSS** — тёмная тема, mobile-first
- **Service Worker** — офлайн-доступ, кеширование статики

### Стек
- `uvicorn` — ASGI-сервер
- `httpx` — HTTP-клиент для Open-Meteo
- `Pillow` — генерация OG-картинок
- `passlib` + `jose` — JWT-аутентификация

## Модель расчёта влажности

### W — текущая влажность (0..1)

W рассчитывается последовательно по почасовым данным:

- **Дождь:** `W += rain_mm / 10` (кап. 1.0)
- **Нет дождя:** `W -= evaporation`
- **Испарение:** `evaporation = forest_coef × (k_t·fT + k_w·gv + k_r·gr + k_s)`
  - `fT = 0.05 × max(temp, 0)` — температурный фактор
  - `gv = 0.03 × wind_speed` — ветровой фактор
  - `gr = 0.001 × radiation` — радиационный фактор
  - `k_t, k_w, k_r, k_s` — коэффициенты типа почвы

### Типы почвы

| Тип | k_t | k_w | k_r | k_s |
|-----|-----|-----|-----|-----|
| asphalt | 0.15 | 0.20 | 0.002 | 0.05 |
| sand | 0.12 | 0.15 | 0.0015 | 0.03 |
| loam | 0.08 | 0.06 | 0.001 | 0.04 |
| clay | 0.05 | 0.03 | 0.0005 | 0.06 |
| clay_heavy | 0.01 | 0.01 | 0.0003 | 0.026 |
| chernozem | 0.07 | 0.05 | 0.001 | 0.05 |

### Лесной коэффициент (forest_coef)

Учитывает затенение деревьями — замедляет испарение:
- Фили: 0.6, Крылатское: 0.6, Ерино: 0.3
- Козловка: 0.3, Чесс: 0.20
- Горы (Архыз, Собер, Новинки): 0.3
- Асфальт (пампы): 1.0

### Статусы грунта

`dry_hours = last_W / evaporation_rate`

| Статус | Условие | Цвет | Эмодзи |
|--------|---------|------|--------|
| Болото | ≥72ч | 🟤 | 🟤 |
| Мокро | >24ч, <72ч | 🔵 | 💧 |
| Альденте | >0, ≤24ч | бирюзовый `#26c6da` | 🌵 |
| Сухо | =0 | 🟢 | ✅ |
| Бетон | асфальт | ⬜ | 🏁 |

### Прогноз на 3 дня

- Использует текущее W из БД (`current_moisture`)
- Применяет прогнозные данные Open-Meteo (температура, ветер, дождь, радиация)
- Дождь в прогнозе: `W += rain/10`
- Вычисляет `dry_hours` для каждого периода (утро/день/вечер)
- Лучшее время: исключает прошедшие периоды и мокро/болото

## API Endpoints

### Погода и статус
- `GET /api/weather/{group}` — Погода + статус для группы парков
- `GET /api/weather/pm/{group}` — Пенман-Монтейт версия
- `GET /api/park/{id}/status` — Статус грунта одного парка
- `GET /api/park/{id}/soil-forecast` — Прогноз грунта на 3 дня
- `GET /api/park/{id}/weather` — Почасовая погода

### Парки
- `GET /api/park/list` — Список всех парков со статусом
- `GET /api/park/{id}/votes-history` — История голосований

### Фото
- `POST /api/park/{id}/photo` — Загрузить фото (base64)
- `GET /api/park/{id}/photos` — Фото парка

### Пользователи
- `POST /api/auth/login` — JWT-логин
- `POST /api/auth/register` — Регистрация
- `GET /api/user/favorites` — Избранное

### Админка
- `GET /admin` — HTML-панель
- `POST /api/admin/login` — Вход
- `POST /api/admin/photo/{id}/approve` — Модерация фото

### Страницы
- `/` — Главная (карточки парков)
- `/park/{id}` — Страница парка
- `/map` — Карта парков
- `/development` — Страница развития проекта
- `/contacts` — Контакты

## Развёртывание

```bash
# Клонировать
git clone https://github.com/Sshneur/mtb-parks-py.git
cd mtb-parks-py

# Установить зависимости
pip install -r requirements.txt

# Запустить
python3 -m uvicorn main:app --host 0.0.0.0 --port 8000
```

На VPS сервер запускается как:
```bash
cd /root/mtb-parks-py
nohup python3 -m uvicorn main:app --host 0.0.0.0 --port 8000 > /root/server.log 2>&1 &
```

### Переменные окружения
- `JWT_SECRET` — секрет для JWT-токенов
- `ADMIN_USERNAME`, `ADMIN_PASSWORD` — учётные данные админа

## Технические детали

- **БД:** SQLite WAL-mode, файл `data/weather.db`
- **Обновление данных:** фоновый планировщик (`updater.py`) загружает историю (1 раз в 3ч) и прогноз (каждые 30 мин)
- **Кеш прогноза:** `soil_forecast_cache` в SQLite, TTL 1 час
- **Офлайн:** Service Worker (`static/sw.js`) кеширует статику, API через networkFirst
- **JWT-токены:** 30 дней, хранятся в `localStorage`
- **Фото:** base64, сохраняются в `data/photos/`, модерация перед публикацией
